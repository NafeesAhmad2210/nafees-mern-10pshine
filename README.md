# 📝 Notes Management Application

## 📌 Overview
The Notes Management Application is a full-stack web application that allows users to securely create, edit, organize, and manage their personal notes. It includes authentication, a rich text editor, and smart categorization features such as Important notes and Trash management.

This project provides a clean and productive experience similar to modern note-taking apps like Google Keep and Evernote. It demonstrates real-world full-stack development practices including authentication, CRUD operations, and database management.

---

## 🚀 Features

### 🔐 Authentication System
- User Sign Up (registration)
- Login with email and password
- Forgot password functionality
- Secure session handling
- Protected routes
- Logout (Sign Out)

---

### 🏠 Dashboard (Home Page)
- Displays the 3 most recent notes
- Quick access to recent work
- Easy navigation to other pages

---

### 📝 Notes Management
- Create new notes
- Edit existing notes
- View all notes
- Delete notes (soft delete system)

---

### ✨ Rich Text Editor
Supports:
- Bold
- Italic
- Underline
- Ordered lists
- Unordered lists

This allows users to write well-structured and formatted notes.

---

### ⭐ Important Notes
- Mark notes as important
- Important notes are shown in a separate page
- Helps users prioritize critical information

---

### 🗑 Trash Management (Soft Delete)
- Deleted notes move to Trash instead of permanent deletion
- Restore notes anytime
- Permanently delete notes when needed
- Prevents accidental data loss

---

### 👤 Profile Page
- Displays user name and email
- Account information management
- Secure sign out option

---

## 📄 Pages Structure
- Home – Shows recent 3 notes
- All Notes – Displays all created notes
- Important – Shows only important notes
- Trash – Restore or permanently delete notes
- Profile – User details and logout
